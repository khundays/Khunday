# Chanoknan Sirikupt | Video Editor Portfolio

## Files
- index.html: the whole site (HTML, CSS, JavaScript, content). Open it in any browser.
- assets/portrait.png: your photo shown in the hero.
- assets/tt1.jpg ... assets/tt20.jpg: TikTok covers for the dr.tangmakkaporn account, in list order (tt1 = first link in the list). Put them in this assets folder. The site accepts .jpg, .png, .jpeg, or .webp, so the extension does not need to be changed.

## Run it
Double-click index.html, or upload the whole folder to a static host (Netlify, GitHub Pages, Vercel).

## Edit your content
1. CONFIG (top of the script): email, social profile URLs.
2. DATA: YT = [videoId, title, creator, featured 1/0]. TT = handle -> comma-separated video IDs.
3. TITLES: titles for YouTube videos that had none in the first list.
4. TEXT: T.en and T.th hold all visible text. Edit both languages together.

## Notes
- YouTube thumbnails load automatically from each video ID.
- TikTok cards show only the account name, with no project title.
- Review the Thai text and the video titles before publishing, especially for an employer audience.
